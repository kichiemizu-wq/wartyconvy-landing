Aturan server VY-JR

Sistem VY-JR dirancang supaya banyak orang bisa main bersama dalam satu server tanpa kekacauan seperti di server publik biasa.

  • 👥

    Server bisa diisi banyak pemain

    Satu server dapat menampung banyak orang sekaligus, jadi cocok dipakai untuk main rame-rame dengan teman atau tim.

  • 🛡️

    Dilarang membunuh tanpa izin

    Setiap pemain wajib meminta izin sebelum menyerang pemain lain. Aturan ini berlaku di semua jenis server, biasa maupun VIP.

  • 💬

    Pelanggaran wajib dilaporkan

    Kalau ada pemain yang melanggar aturan, korban berhak melapor langsung ke admin lengkap dengan bukti kejadian.

Kalau ada pelanggaran

Laporan ditangani langsung oleh admin, bukan sistem otomatis, supaya setiap kasus dicek dengan adil.

  • 1. Kirim laporan ke admin via WhatsApp, sertakan waktu kejadian dan nama pelaku.
  • 2. Lampirkan bukti (screenshot atau rekaman) kalau ada.
  • 3. Admin meninjau laporan dan mengambil tindakan sesuai aturan server.
